This is a coverage story, not a dead end

Sparse software→publication links are common across young or informally-published research software — the code exists and is used, but nothing yet connects it to a DOI, an ORCID record, or a CITATION.cff file that Open Pulse's extractors can follow. Closing this gap is an upstream metadata task for these teams' maintainers, not a limitation of this dashboard. See What's missing for the actionable list.
